# Module Guide

The folders and files for the module guide.

- `MG.tex`: the Module Guide.
- `BackendArchitecture.md`: the backend's high-level design: its modules, the
  rules between them and the patterns they share.
- `modules/`: one doc per backend module, such as `modules/trading.md`.
- `figures/`: the UML diagrams. Each `.puml` file is the source of the `.png`
  next to it.
